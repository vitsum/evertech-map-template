# Evertech Sandbox — шаблон кастомной карты

**Языки:** [English](README.md) · Русский · [Bahasa Indonesia](README.id.md)

Этот Unity-проект — шаблон для создания собственных **кастомных карт** для Evertech Sandbox.
Откройте, отредактируйте сцену, соберите и положите результат в игру.

---

## Требования

- **Unity 2022** — используйте версию, на которой идёт шаблон (2022.3.x). Подойдёт любой 2022.x;
  игра сверяет только год. (См. *Версия Unity* ниже.)
- Рендер-пайплайн — **URP**, уже настроен. Не меняйте его.

---

## Что внутри

| Путь | Что это |
|---|---|
| `Assets/Scene.unity` | Сцена карты. **Именно она собирается в карту.** Имя её AssetBundle — `scene`, не меняйте. |
| `Assets/MapScripts/` | Маркеры карты (`PlayerSpawnPoint`, `WaterLevel`, `LadderVolume`). |
| `Assets/MapSDK/` | SDK настроек карты — позволяет добавлять игровые настройки **без кода**. |
| `Assets/Editor/AssetBundleCreator.cs` | Инструмент сборки (меню **Custom Tools → Build Map …**). |
| `Assets/AssetBundles/` | Результат сборки + ваши `info.json` и `preview.png`. Эта папка и становится картой. |

Открыв `Assets/Scene.unity`, вы увидите рабочий пример. Изучите его, затем удалите
объект `--- Map Settings Example (delete me) ---` и делайте свою карту.

---

## 1. Соберите сцену

Редактируйте `Assets/Scene.unity` как угодно — рельеф, объекты, освещение и т.д.

> ⚠️ **НЕ добавляйте камеру.** Игрока и камеру даёт игра.
> ⚠️ Держите всё в **одной этой сцене** — в карту собирается только `Assets/Scene.unity`.

### Маркеры (все необязательны)

- **Player Spawn Point** — пустой GameObject + компонент **`PlayerSpawnPoint`**.
  Задаёт, где появляется игрок и куда смотрит (синяя ось **Z / forward**).
  **Необязателен** — без него игрок появится в дефолтной точке (начало координат).
- **Water Level** — пустой GameObject + компонент **`WaterLevel`**.
  **Мировая Y** объекта = высота поверхности воды.
  **Необязателен** — без него игра использует свой дефолтный уровень воды.
  - Когда камера опускается ниже этой Y, игра включает подводный эффект (цветной оверлей на экране).
  - **Свой вид под водой (необязательно):** включите **Override Appearance** и задайте свой
    **Tint Color** (RGB; альфа = насыщенность) и галочку **Play Sound** (звук под водой).
    Если оставить выключенным — карта использует стандартный подводный эффект игры.
- **Зона лазания по лестнице** — GameObject + компонент **`LadderVolume`** (сам добавляет **BoxCollider**).
  Это **невидимый триггер-объём ПЕРЕД вертикальной лестницей** — это *не* сама лестница, а только
  зона «захвата»: игрок входит в бокс и начинает лезть (как по штатным лестницам).
  - У самой лестницы **должен быть свой сплошной коллайдер** — одна плоская стенка-коллайдер на всю
    лестницу (**не по каждой перекладине**), чтобы игрок упирался в неё и не проваливался.
    `LadderVolume` — только триггер и этого коллайдера *не* даёт.
  - Ставьте бокс **прямо перед** этой сплошной поверхностью, по размеру досягаемой зоны лазания
    (небольшое пересечение с лестницей — нормально).
  - Держите объект **вертикально**; игрок лезет вдоль его локальной оси **Up (зелёная Y)**.
  - 👉 Смотрите готовый пример **`Ladder`** в `Assets/Scene.unity`: сплошной коллайдер-стенка
    (`Ladder`) с перекладинами-детьми и триггер `LadderVolume` прямо перед ним. Скопируйте эту
    связку для своих лестниц.

## 2. Настройки карты — опции для игроков (необязательно, без кода)

SDK позволяет игрокам менять вашу карту из игровой панели **World Settings**.

### Шаг A — объявите настройки

Добавьте **один** пустой GameObject с компонентом **`MapSettingsDeclaration`** и заполните список `settings`.
Каждый элемент — одна настройка:

| Тип | Вид в игре | Поля для заполнения |
|---|---|---|
| **Bool** | Переключатель | `key`, `label`, `defaultBool` |
| **Slider** | Ползунок | `key`, `label`, `min`, `max`, `step` (0 = плавно), `defaultFloat` |
| **Enum** | Выпадающий список | `key`, `label`, `options[]`, `defaultOption` |

`key` — уникальный идентификатор (например, `showDecorations`). `label` — текст, который видит игрок.

### Шаг B — пусть настройки что-то делают (готовые ресиверы, без кода)

Добавьте любой из этих компонентов и укажите в его `key` объявленную настройку:

| Компонент | Тип | Что делает |
|---|---|---|
| **`SettingToggleObject`** | Bool | Показывает/прячет объекты из `targets`. |
| **`SettingEnumObjects`** | Enum | Включает один объект из `optionObjects` на каждый вариант (индекс = порядок опции). |
| **`SettingSwapMaterial`** | Bool / Enum | Меняет материалы (`materials`) на указанных `renderers` (Bool: 0 = выкл, 1 = вкл; Enum: индекс = опция). |
| **`MapSettingBinding`** | Любой | Универсальный. Привяжите его **UnityEvent** `onBool` / `onFloat` / `onOption` в инспекторе к чему угодно встроенному. |

> У **слайдера** нет отдельного ресивера — используйте **`MapSettingBinding`**:
> укажите `key` слайдера, затем в инспекторе перетащите цель в событие **`onFloat`** и выберите
> float-сеттер (например, `Light.intensity`, `AudioSource.volume`). Событие срабатывает при загрузке и при каждом изменении.

**Ключи должны быть уникальны** и совпадать между объявлением и ресиверами/привязками.

В сцене есть живой пример под объектом `--- Map Settings Example (delete me) ---`
(Bool-тоггл прячет кубы, Enum переключает формы). Удалите весь этот объект перед публикацией.

## 3. Заполните информацию о карте

Отредактируйте два файла в `Assets/AssetBundles/`:

- **`info.json`** (обязателен — карта без `info.json` не появится в игре)
  ```json
  {
      "name": "Название карты",
      "author": "ВашНик",
      "version": "1.0",
      "description": "Короткое описание для браузера карт"
  }
  ```
- **`preview.png`** — превью на карточке карты. Держите **маленьким** — хватит примерно **300×200**.
  Не кладите огромный скриншот в полном разрешении — он только раздувает карту.

---

## 4. Соберите карту

Меню: **Custom Tools → Build Map for all platforms**
Для быстрой сборки под одну платформу есть также **Build Map for Android only**, **Build Map for Windows only** и **Build Map for iOS only** — но каждая «only»-сборка сначала **очищает вывод остальных платформ** и пересобирает только выбранную.

Бандлы запишутся в `Assets/AssetBundles/<Platform>/` для всех платформ, которые использует игра:
`Android`, `Windows64`, `iOS`.

---

## 5. Соберите финальную папку карты

Игра ждёт папку карты такого вида — **`info.json` и `preview.png` в корне**, по папке на платформу, в каждой — только файл `scene`:

```
<МояКарта>/
  info.json
  preview.png
  Android/scene
  Windows64/scene
  iOS/scene
```

Хорошая новость: после сборки `Assets/AssetBundles/` уже содержит `info.json`, `preview.png`
и платформенные папки — то есть это **и есть** ваша папка карты. Просто скопируйте её и переименуйте.
**Имя папки = id карты**, так что дайте уникальное.

> В каждой платформенной папке нужен только файл **`scene`**. Лишние `*.manifest` и одноимённые
> папке файлы-бандлы — мусор сборки, их можно удалить для чистоты (игра их игнорирует).

---

## 6. Установите и проверьте в игре

Положите папку `<МояКарта>` в **папку maps** игры, затем запустите игру — карта появится в списке карт,
оттуда её можно открыть (Open).

Папка maps лежит внутри сохранений игры:

- **Windows:** `%USERPROFILE%\AppData\LocalLow\IronTube Games\Evertech Sandbox\maps\`
- **Мобильные:** папка данных приложения, `…/Evertech Sandbox/maps/`

То есть итоговый путь, например:
`…\Evertech Sandbox\maps\<МояКарта>\info.json`, `…\maps\<МояКарта>\Windows64\scene` и т.д.

---

## Версия Unity

Игра сверяет **год** Unity, на котором собрана карта (должен быть **2022**).
- Сборка на любом патче **2022.x** — нормально; мелкие различия (например `2022.3.56` против `2022.3.62`)
  в худшем случае дают незначительную разницу в отображении.
- Сборка на **другой мажорной версии** (2021, 2023, 6000, …) — игра пометит карту как
  *не поддерживается* в списке карт. Держитесь 2022.

## Частые ошибки

- ❌ Добавили камеру в сцену → у игры она уже есть. Уберите.
- ❌ Переименовали `Assets/Scene.unity` или сменили имя AssetBundle → должно остаться `scene`.
- ❌ `info.json` / `preview.png` положили внутрь платформенной папки → они идут в **корень** папки карты.
- ❌ Нет `info.json` → карта вообще не появится в списке игры.
- ❌ Две настройки с одинаковым `key` или `key` ресивера не совпадает с объявлением.
